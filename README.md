# 🌦️ Análise Meteorológica com Excel Avançado

Projeto de análise de dados meteorológicos utilizando **Microsoft Excel** com tabelas dinâmicas, campos calculados e gráficos interativos.

## 📊 O que foi feito

- Temperatura mínima, máxima e média por mês e ano  
- Tempo de chuva total convertido em horas  
- Média da umidade relativa do ar  
- Gráficos de linha, colunas e combinados  
- Segmentações interativas por mês e ano
